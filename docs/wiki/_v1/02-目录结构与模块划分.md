## 3. `api/` 路由地图

`api/__init__.py` 统一装配，`api/app.py` 负责中间件与异常映射。

### 3.1 装配层

| 文件 | 职责 |
|---|---|
| `app.py` | `create_app()`：异常处理器（配额 429 / 额度 402 / 计费规则 409 / 授权 403）、请求体大小限制（普通 5 MB，上传走 `MAX_PROJECT_UPLOAD_BYTES`）、资源请求日志、`/healthz`、启动恢复（lifecycle 端口、WAL 迁移、官方模型目录轮询、Director Auto 恢复）、可选 SPA 静态托管（`DRAMACLAW_FRONTEND_DIST`） |
| `__init__.py` | `api_router`（前缀 `/api/v1`）+ 路由注册 + `OPENAPI_TAGS`（freezone 分 10 个 tag）+ 验证路由延迟注册 |
| `auth.py` | `get_api_user` / `require_scope` 依赖 |
| `deps.py`、`responses.py`、`schemas.py` | 依赖注入、统一响应封装、Pydantic 模型 |
| `wsgi.py` | 生产 WSGI 入口（**必须先 `load_project_dotenv()` 再导入 app**，ruff 对该文件永久豁免 E402） |
| `gunicorn_worker.py` | gunicorn worker 配置 |

> CE 模式下 `api/__init__.py` **不加载** `novelvideo.api_routes` entry point 组——EE 的额外路由通过该组注入，CE 直接跳过。这是 CE/EE 路由隔离的落点。

### 3.2 路由模块（25 个）

| 分组 | 文件 | 典型端点 |
|---|---|---|
| 项目 | `projects.py` | `GET/POST /projects`、`PATCH /projects/{project}`、归档/删除/恢复/清除、旁白音色上传 |
| 摄取 | `ingest.py` | `POST /projects/{p}/ingest/upload`、`/ingest/start`、`GET .../ingest/graph` |
| 内容 | `content.py`、`scripts.py` | 原文/改编稿读写与重写、`POST .../script/generate`、beat 编辑与视频提示词生成 |

| 资产 | `characters.py`、`scenes.py`、`props.py`、`assets.py` | 角色形象/音色样本、场景参考图、道具三视图、资产上传与元数据 |

## 4. `task_backend/` 任务执行

| 文件 | 职责 |
|---|---|
| `registry.py` | `register_project_task_runner()`：任务类型 → runner + **放置声明**（是否必须在家节点、走哪条 lane）。路由与守卫读同一来源，避免"路由器认为可漂移、守卫仍拒绝"的双真相 |
| `queues.py` | 4 条 lane：`default` / `video` / `world` / `ffmpeg`；队列名格式 `node.<home_node>.<lane>`。**拼错 lane 直接抛错**，不静默回落 default |
| `run_core.py`、`client.py`、`consumer.py`、`producer.py` | 执行核心与投递/消费 |
| `envelope.py`、`signing.py` | 任务信封与 HMAC 签名（防投递途中身份被改写） |
| `limits.py`、`limit_logging.py` | 配额守卫（项目 / 项目-用户 / 全局 lane / 渠道 / 用户五级） |
| `cancel.py`、`projection.py`、`subprocesses.py` | 取消、状态投影、子进程管理 |
| `runners/` | 17 个 runner 模块，注册 **28 种任务类型**（见 [03 §3](03-核心功能与流程.md#3-任务生命周期)） |

## 5. 前端结构（`frontend/src/`）

```
src/
├── routes/            # TanStack 文件式路由（routeTree.gen.ts 由插件生成，勿手改）
│   ├── _app/          # 登录后主壳
│   │   ├── index.tsx              # 项目列表
│   │   └── projects.$project/     # 项目工作台
│   │       ├── ingest.tsx / styles.tsx / tasks.tsx / characters.lazy.tsx
│   │       ├── freezone.lazy.tsx  # 虾画画布
│   │       └── episodes.$episode/ # 单集七个页签
│   │           overview / script / beats / sketches / video / audio / compose
│   ├── login.tsx / download.lazy.tsx / watch.$work.tsx / checkout.tsx / recharge.tsx
├── features/          # 领域功能块（画布、超聊、技能导入、小游戏、奖励…）
├── components/        # 可复用组件（shadcn 原语、布局、资产、任务中心、设置）
├── task-center/       # 任务中心内核：SSE 流客户端、事件总线、订阅 hooks、错误映射
├── api/               # 后端接口封装（client/ky、canvas、tasks、assets、skills…）
├── stores/            # 13 个 Zustand store（画布、认证、主题、保存状态、项目导航…）
├── lib/               # 工具函数（api-path、错误映射、比例、音频转码、确认重命名…）
├── pipeline-import/   # 分镜/参考图导入画布（掩码编辑、抽帧、对比）
├── i18n/              # i18next 资源与初始化
├── commands/          # 命令式 API（如 image.ts）
└── index.css          # ★ 视觉 token 源；改它必须同步 DESIGN.md
```

**三个容易踩的约定**：

1. **路由文件带 `.lazy.tsx` 后缀 = 该路由走代码分割**，不应改成同步导入。
2. `routeTree.gen.ts` 是**生成物**，改路由结构后由插件重新生成，不要手改。
3. 所有颜色/圆角/间距/动效必须从 `index.css` 的 CSS 变量取，**禁止在组件里写死 hex/px/ms**（`DESIGN.md` 的 Do's and Don'ts 明文规定）。
